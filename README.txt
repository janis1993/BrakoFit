BrakoFit V5.6 Stable, veidots no iesūtītās strādājošās V5.5 versijas. Pabeigts treniņš pēc saglabāšanas tiek noņemts no kalendāra; kalendārs slēpj arī vecos done ierakstus. Vēstures redaktorā var pārsaukt, pievienot un dzēst vingrinājumus, pievienot/dzēst setus, un ir skaidras KG/Reizes galvenes. Lokālā datu atslēga palikusi brakofit-v54, lai telefona dati saglabātos. Pirms GitHub atjaunināšanas eksportē rezerves kopiju.
